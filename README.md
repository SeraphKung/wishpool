## 收件方式
原生 HTML form 以 HTTPS POST 對應現有 Google Forms 的 formResponse，回應顯示於站內 iframe。沒有 API 金鑰、沒有公開收件清單、沒有把願望寫入 GitHub。這個端點是 Google 表單網頁提交機制，並非有相容性保證的官方 Forms 寫入 API；更改題目或 Google 行為後必須重測。

JavaScript 僅處理防止連點、捲動與狀態提示。不能讀取跨來源 iframe，因此不以 load 或 opaque fetch 回應假稱成功。使用者須看見 Google 成功確認文字；無 JS 時仍可提交。資料不存 localStorage；傳輸失敗時保留原填寫內容。原表單連結作為備援。
